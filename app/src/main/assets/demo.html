1. JS → Native 同步 JS→Native

@JavascriptInterface 直接调用；可有返回值（在 WebView 线程同步返回）。

2. 异步回调 / Promise 双向

Native 延时处理后 evaluateJavascript 回调；JS 侧用 Promise 包装，贴近现代 H5 写法。

3. WebChromeClient 经典拦截 系统

网页自带的 alert / confirm / prompt / console 由 Native 接管（不依赖桥对象）。

4. URL Scheme 拦截 JS→Native

shouldOverrideUrlLoading 拦截自定义协议，适合 a 标签 / location.href。

jsbridge://scan 传经纬度 Scheme Toast 外开浏览器 tel:10086 mailto

5. 系统能力 Intent

剪贴板、分享、拨号、短信、邮件、外链 —— Hybrid App 最常用系统出口。

6. 文件选择 双向

两条路径：桥方法 pickFile()，以及 HTML <input type=file> + onShowFileChooser。

模拟下载监听

7. 权限 + 扫码 双向

运行时申请 CAMERA，打开 ZXing，结果回写 setScanResult。

Scheme 扫码

8. 页面控制 JS→Native

由 H5 驱动 WebView 导航 / 关闭 Activity，常见于容器型 App。

9. H5 本地存储 Web API

验证 WebView 已开启 domStorage；可与 Native 数据通道配合使用。

10. Cookie 同步 双向

Native CookieManager 读写，常用于登录态注入 H5。

11. 定位 权限

运行时申请定位权限，回传 lastKnownLocation（演示向，非持续定位）。

12. Base64 图片 双向

相册选图 → Native 压缩 → data:image/jpeg;base64,... 回传 H5 展示。

13. 白名单 + Token 鉴权 生产向

secureCall 要求：当前页在受信来源（assets / localhost）且 token 正确。演示 token：demo-token-jsandroid

14. Native → JS Native→JS

点 App 顶部「Native→JS」：Native 用 evaluateJavascript 调用本页 onNativeMessage。也可点下面按钮自测注入。
